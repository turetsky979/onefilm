# 添加真实截图（可选）

README 顶部目前用一段**文字界面示意图**展示面板布局。这是为了在没有截图时也能让页面完整可读——纯文本在 GitHub 上渲染稳定，不会出现坏图。

如果你希望换成真实截图，按下面两步操作：

## 1. 放截图文件

将面板截图保存为 `docs/screenshot.png`（推荐 16:9 或更宽的横向图，便于 README 展示）。

建议截图内容：
- 顶部搜索框
- 搜索结果列表（含一个已展开的文件夹，能看到大小）
- 底部下载进度区域（含进行中 / 已完成两条）

注意打码掉隐私信息：文件名、群 ID、本地磁盘路径、网盘账号等。

## 2. 替换 README 中的示意图

打开 `README.md`，把这一段（从 `**界面一览**` 开始到说明文字结束的整个代码块）：

````markdown
**界面一览**（文字示意，实际为深色圆角卡片 + 任务状态灯）：

```
  ONEFILM ...
```
````

替换为：

```markdown
![ONEFILM 面板](docs/screenshot.png)
```

提交并推送后，GitHub 项目首页就会显示你的真实截图。
